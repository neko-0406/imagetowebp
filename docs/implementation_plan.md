# WebP画像形式変換ツール（Rust実装）開発計画書

ブログ等に掲載するJPG/PNG画像をWebP形式に高効率・高速かつ堅牢に変換するRust製CLIツールの開発計画です。

---

## 1. プロジェクト目標と特長

- **柔軟な入力指定**: ファイル単体指定、複数ファイル一括指定、フォルダ全体の指定（再帰検索）をシームレスにサポート。
- **超高速処理**: `rayon` を利用したマルチスレッド並列処理により、大量の画像を一括で高速変換します。
- **堅牢性**: 個々の画像変換でエラーが発生しても処理全体をストップさせず、適切なエラーログを出力して継続します。
- **ブログ最適化機能**: 画質（クオリティ）調整、可逆/非可逆選択、長辺リサイズ（縦横比維持）などの最適化オプションを提供します。
- **使いやすいUI/UX**: コマンドライン引数指定と、引数なし実行時の対話型モード（ウィザード形式）の両方に対応し、プログレスバーでリアルタイムに進捗を表示します。

---

## 2. システム機能要件

### (1) 入力・検索機能
- **ファイル単位指定**: 単一または複数の画像ファイルパスを直接指定可能（例: `imagetowebp image1.png image2.jpg`）。
- **フォルダ単位指定**: 1つ以上のディレクトリパスを指定可能。指定されたフォルダ内を `walkdir` により再帰的に画像を検索。
- **混在指定**: フォルダパスとファイルパスを混在して指定可能。重複ファイルは自動でデデュプ（除外）。
- 対象拡張子: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tiff` （大文字小文字不問）。

### (2) 画像変換・最適化機能
- **WebPエンコード**: 画質（0~100%、デフォルト: 80%）設定、Lossless（可逆）/ Lossy（非可逆）切り替え。
- **自動リサイズ**: オプションで最大幅・最大高さを指定し、縦横比を維持したままリサイズ（例: ブログ用 1920px 制限）。
- **Exif/カラープロファイル対応**: 安全な読み込みとエンコード処理。

### (3) 出力・安全機能
- **出力先指定**: 元画像と同じディレクトリ、または指定した出力ディレクトリ（構造保持/フラット保存）。
- **上書き制御**: 同名ファイルが存在する場合、デフォルトではスキップし、`--overwrite` オプション指定時のみ上書き。

### (4) UI / 統計出力
- **プログレスバー**: `indicatif` を用いたプログレスバーで進捗可視化。
- **結果サマリー**: 処理完了時に以下を出力
  - 成功数 / スキップ数 / 失敗数
  - 変換前後の総ファイルサイズと削減率（例: `12.5 MB -> 4.2 MB (66.4% 削減)`）
  - 全体処理時間

## 3. モジュール設計（アーキテクチャ）

```
src/
├── main.rs         # エントリーポイント、全体のフロー制御
├── cli.rs          # Clapを用いたコマンドライン引数解析 & 対話プロンプト (dialoguer)
├── config.rs       # 変換オプション設定構造体
├── converter.rs    # 単一画像の読み込み・リサイズ・WebP変換ロジック
└── processor.rs    # ファイル/フォルダパス収集・重複排除、Rayon並列処理、プログレスバー管理、統計集計
```

---

## 4. 実装ステップ計画

1. **Step 1: 設定およびCLIモジュールの作成 (`cli.rs`, `config.rs`)**
   - コマンドライン引数の定義（ファイル/フォルダの可変引数入力、出力パス、画質、リサイズ、上書き設定など）。
   - 引数なし起動時の対話型プロンプト（「フォルダ指定」or「ファイル指定」を選択できるウィザード）の実装。

2. **Step 2: WebP変換コアエンジンの実装 (`converter.rs`)**
   - `image` crate での画像読み込みとリサイズ処理。
   - `webp` crate を用いた WebP エンコード処理。
   - エラー処理（`anyhow` による失敗のハンドリング）。

3. **Step 3: パス解析・並列処理パイプラインとUIの実装 (`processor.rs`, `main.rs`)**
   - ファイル直接指定と `walkdir` ディレクトリ探索を組み合わせた対象画像リストの収集・重複排除機能。
   - `rayon` による並列処理と、安全なスレッド間統計カウント。
   - `indicatif` によるリアルタイムプログレスバー表示。

4. **Step 4: ビルド・動作確認およびテスト**
   - 単一ファイル指定、フォルダ指定、混在指定のテスト。
   - 変換精度・圧縮率・速度を検証。
