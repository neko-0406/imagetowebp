# WebP画像変換ツール (imagetowebp) 全体計画・設計書

ブログ掲載用画像を WebP 形式へ変換する高速・堅牢な Rust ツール `imagetowebp` の設計ドキュメントです。

---

## 1. システム要件・設計方針

### 高速性 (Performance)
- `rayon` スレッドプールを使用した並列画像ロード・リサイズ・WebPエンコード。
- ディレクトリツリーの探索には `walkdir` を使用し、並列処理キューへ供給。

### 柔軟な入力指定 (Flexible Input)
- **ファイル単位指定**: 個別の画像ファイルを1つ〜複数指定して処理。
- **フォルダ単位指定**: ディレクトリを指定し、内部の画像ファイルを再帰的に検索・一括処理。
- **混在指定**: ファイルとフォルダを同時に指定可能。重複ファイルパスは自動で排除。

### 堅牢性 (Robustness)
- 個々のファイルで入出力エラーや画像データ破損が発生しても、エラーメッセージを表示して他ファイルの処理を継続。
- `anyhow` による詳細なエラー情報の追跡。
- `.webp` ファイルは変換対象から自動除外（変換済みファイルの再処理防止）。

### ブログ最適化 (Blog Optimization)
- 画質パラメータ (`--quality`, `-q`): 1~100 (デフォルト: 80)。CLIレベルで範囲を強制。
- 可逆 / 非可逆 (`--lossless`, `-l`): Lossless 選択時は quality パラメータを無視し可逆エンコードを行う。
- リサイズ (`--max-dimension`, `-m`): 画像の長辺が指定ピクセルを超える場合、アスペクト比を保って自動縮小。

### 安全性と利便性 (Safety & Usability)
- 上書き防止 (デフォルト): 同名 `.webp` ファイルが存在する場合はスキップ。
- 上書き許可 (`--overwrite`, `-w`): フラグ指定時に上書き。
- 出力先ディレクトリ制御: 未指定時は元画像と同階層に保存。
- **構造保持オプション** (`--preserve-structure`, `-s`): フォルダ指定変換時に出力先でサブフォルダ構造を維持し、同名ファイルの衝突を防止。

## 2. 内部モジュール構造

```
src/
├── main.rs         # プログラムのエントリーポイントと実行制御
├── cli.rs          # Clap引数定義および対話型プロンプト (dialoguer)
├── config.rs       # 変換オプションを保持するデータ構造
├── converter.rs    # 画像読み込み、リサイズ、WebPエンコードコア処理・出力パス解決
└── processor.rs    # パス解析（ファイル/フォルダ判定・収集）、並列処理、プログレスバー、統計集計
tests/
└── integration_test.rs  # エンドツーエンド統合テスト
```

## 3. 主要な設計決定事項

### ConvertConfig 構造体のフィールド
| フィールド | 型 | デフォルト | 説明 |
|:---|:---|:---:|:---|
| `input_paths` | `Vec<PathBuf>` | - | 変換対象のパス一覧 |
| `output_dir` | `Option<PathBuf>` | `None` | 出力先ディレクトリ |
| `quality` | `u8` | `80` | WebP画質 (1〜100)。lossless時は無視。 |
| `lossless` | `bool` | `false` | 可逆圧縮モード。trueのとき qualityは無視される。 |
| `max_dimension` | `Option<u32>` | `None` | 長辺最大ピクセル数 |
| `overwrite` | `bool` | `false` | 同名WebPの上書き許可 |
| `preserve_structure` | `bool` | `false` | 出力先でサブフォルダ構造を保持する |

### ファイル名衝突防止の仕組み (`preserve_structure`)
- `false` (デフォルト): 出力先をフラットに展開（ファイル名のみで出力）
- `true`: 入力ルートからの相対パスを出力先に再現する

```
例: -i ./images -o ./out -s を使用した場合

入力:  ./images/blog/header.png
出力:  ./out/blog/header.webp   ← サブフォルダ構造が保持される
```
