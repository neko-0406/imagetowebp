# WebP画像変換ツール (imagetowebp) 全体計画・設計書

ブログ掲載用画像を WebP 形式へ変換する高速・堅牢な Rust ツール `imagetowebp` の設計ドキュメントです。

---

## 1. システム要件・設計方針

### 高速性 (Performance)
- `rayon` スレッドプールを使用した並列画像ロード・リサイズ・WebPエンコード。
- ディレクトリツリーの探索には `walkdir` を使用し、非同期・並列処理キューへ供給。

### 柔軟な入力指定 (Flexible Input)
- **ファイル単位指定**: 個別の画像ファイル（`sample.jpg` 等）を1つ〜複数指定して処理。
- **フォルダ単位指定**: ディレクトリ（`./images/` 等）を指定し、内部の画像ファイルを再帰的に検索・一括処理。
- **混在指定**: ファイルとフォルダを同時に指定可能。重複ファイルパスは自動で排除。

### 堅牢性 (Robustness)
- 個々のファイルで入出力エラーや画像データ破損が発生しても、エラーメッセージを表示して他ファイルの処理を継続。
- `anyhow` による詳細なエラー情報の追跡。

### ブログ最適化 (Blog Optimization)
- 画質パラメータ (`quality`): 1~100 (デフォルト: 80)
- 可逆 / 非可逆 (Lossless / Lossy): 画像の種類や目的に応じて設定
- リサイズ (`max-dimension`): 画像の長辺が指定ピクセルを超える場合、アスタクト比を保って自動リサイズ

### 安全性と利便性 (Safety & Usability)
- 上書き防止 (デフォルト): 同名 `.webp` ファイルが存在する場合はスキップ。
- 上書き許可 (`--overwrite`): フラグ指定時に上書き。
- 出力先ディレクトリ制御: 未指定時は元画像と同階層に保存。

## 2. 内部モジュール構造

```
src/
├── main.rs         # プログラムのエントリーポイントと実行制御
├── cli.rs          # Clap引数定義および対話型プロンプト (dialoguer)
├── config.rs       # 変換オプションを保持するデータ構造
├── converter.rs    # 画像読み込み、リサイズ、WebPエンコードコア処理
└── processor.rs    # パス解析（ファイル/フォルダ判定・収集）、並列処理、プログレスバー、統計集計
```

---

## 3. 実装ステップ

### Step 1: CLI / 設定モジュールの実装
- `clap` による複数ファイル/フォルダ入力引数定義
- `dialoguer` を使用した対話形式（「ファイル指定」または「フォルダ指定」の選択肢）プロンプト

### Step 2: 変換エンジンの実装
- `image` crate による画像解読・リサイズ
- `webp` crate による WebP エンコード (lossy / lossless)

### Step 3: ディレクトリ/ファイル解析・並列処理・統計表示の実装
- 入力引数がファイルかフォルダかを判定し、画像ファイルパスの一覧を取得（重複排除）
- `rayon` による並列変換パイプライン構築
- `indicatif` プログレスバー更新と統計（削減容量・パーセンテージ）表示

### Step 4: テストと検証
- 単一ファイル指定、フォルダ指定、混在指定での動作検証
- 壊れた画像に対するエラーリカバリテスト
